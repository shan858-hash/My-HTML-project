Designed to assist new users with hand-coding a Web site

This tutorial will walk you through the steps necessary to make a basic Web site. It provides you with an understanding of the essential elements of HTML.

By the end of this tutorial you will have a basic knowledge of:

  • Structure an HTML tag.
  • Store an HTML page.
  • Modify the appearance of your HTML text.
  • Create lists and tables within your Web page.
